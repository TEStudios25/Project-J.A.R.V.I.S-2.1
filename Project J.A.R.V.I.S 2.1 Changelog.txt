## 🔮 THE 2.1 HIGHLIGHTS: WAKING UP THE ASSISTANT (July 2026 Build)
1. 🌐 **3D Holographic Arc Reactor Orb**  
   Designed a secondary, concurrent WebGL visualizer window using Three.js. Features latitude/longitude orbiting wireframes, a glowing geodesic core, space dust particles, and UnrealBloomPass post-processing.
   
2. 🖐️ **MediaPipe Hand Gesture Recognition**  
   Integrated a real-time webcam tracking module that allows rotating the 3D Orb with single-hand gestures, resetting visualizers, and zooming in/out by adjusting the distance between two hands.

3. 🎙️ **Double-Clap Wake & Standby System**  
   Implemented a background PortAudio callback stream using `sounddevice` at 44.1 kHz. Saying *"standby"* completely closes the microphone driver to reduce CPU and protect privacy. Clapping twice plays a digital chime, wakes the system up, and triggers the wake greeting. Handles dynamic stream closing to prevent Windows driver conflicts.

4. 📥 **System Tray Minimization**  
   Configured the PyQt Command Center dashboard to hide into the Windows System Tray (glowing cyber-cyan icon) when clicking `[X]`. Background voice and clap listeners remain fully armed.

5. ⌨️ **Global Alt+V Mic Hotkey Toggle**  
   Bound `Alt + V` as a global keyboard shortcut. Toggles the mic state instantly from any active window (or while minimized to the tray) and displays a quick tray notification message.

6. 🛡️ **Active App Audio Shield**  
   Polls the foreground window title every 1.5 seconds. If you focus on a window playing media (YouTube, Instagram Reels, Spotify, Netflix) or join a call (Discord, Zoom, Teams), J.A.R.V.I.S. auto-mutes the mic to protect your audio privacy and avoid false speech recognition triggers.

7. 📹 **Multimodal Video Analyzer Tool**  
   Added `yt-dlp` media streaming and a Gemini video analysis pipeline. J.A.R.V.I.S. can now download public video links (Instagram Reels, YouTube) or process local MP4 files frame-by-frame, describing scenes, memetics, or transcribing audio on command.

8. ⚙️ **DSP Robotic Voice Modulator**  
   Edge-TTS voice streams are pitched down by 1.1x and modulated with a 45Hz LFO ring modulator in Pygame Sound channels, creating a deep, metallic, realistic robotic voice.

9. 🔥 **GenZ Sarcastic & Lively Persona**  
   Re-calibrated system prompt guidelines to make J.A.R.V.I.S. lively, witty, and sarcastic. He uses dry humor and subtle GenZ expressions (*fr*, *no cap*, *lowkey*, *bet*, *bruh*) instead of corporate, blunt answers.

10. ⚡ **Fast Dynamic Booting**  
    Cleaned up vocal clutter during startup. Subsystem checks are logged to the console/GUI but only a single, caffeinated dynamic greeting is spoken, saving 40 seconds of boot time. Also ignores old memory backlog tasks on startup if relaunching after a break of more than 4 hours.

11. 🎙️ **USB Mic Auto-Detection**  
    Scans PortAudio device indexes on boot to prioritize hardware inputs (USB Audio Device) over virtual silent drivers (like DroidCam Audio), resolving input loss bugs.

12. 🛡️ **Ambient Calibration Speaking Guard**  
    Connected calibration thresholds in the speech recognizer to check J.A.R.V.I.S.'s speech state, preventing the microphone from calibrating during startup greetings and deafening the system.

13. ⌨️ **PTT Keyboard Hook Purging**  
    Completely removed keyboard hooks and push-to-talk background threads to prevent PortAudio thread locks and concurrency driver crashes.

14. 🖥️ **Desktop Launcher & Auto-Boot Realignment**  
    Configured absolute directory paths in `J.A.R.V.I.S 2.1.bat` on the Desktop and `Jarvis.lnk` in the Startup folder, allowing smooth execution under pythonw.exe.

## 🔰 THE 2.0 HIGHLIGHTS: MASSIVE SYSTEM OVERHAUL
1. 🖥️ **Sci-Fi Graphical User Interface (GUI)**  
   Completely abandoned the standard text terminal for a gorgeous, frameless PyQt5 GUI. Features a central holographic arc-reactor animation, Matrix-green dynamic boot logs, a real-time HUD status bar, and a custom-styled cyber-terminal input box.

2. 🧠 **The Gemini Native Brain Integration**  
   Migrated from legacy Groq APIs to the highly advanced Google Gemini API engine. J.A.R.V.I.S. now utilizes Native Function Calling, allowing the AI to autonomously decide when and how to trigger physical tools without relying on rigid, hardcoded if/else word detection.

3. ⚡ **Multi-Threaded Nervous System**  
   Rewrote the core architecture to run asynchronously. The Brain, Voice Engine, Microphone, and Visual Interface now run on separate, synchronized background daemon threads. The screen never freezes, even when J.A.R.V.I.S. is speaking or thinking.

4. 🎙️ **Flawless Voice & Text Routing (Infinite Standby)**  
   Removed the clunky "Voice or Text" startup prompt. The system now features a real-time GUI Mic Toggle. The microphone rests in pure, infinite standby with zero "phantom processing," perfectly filtering out room static until explicitly spoken to. 

5. 👁️ **Optical Character Recognition (OCR) Vision**  
   Integrated local OCR processing using pytesseract and OpenCV, officially giving J.A.R.V.I.S. the ability to "see" and extract text, detect objects (faces/eyes), identify shapes, and analyze colors directly from local visual data entirely offline.

6. 🛑 **Absolute Control: The Override & Kill Switch**  
   Added the ability to type or say "Stop", "Pause", or "Resume" to instantly cut or pause J.A.R.V.I.S. mid-sentence via direct Pygame audio stream manipulation. Integrated a master shutdown protocol that cleanly kills all processes, bids farewell, and closes the application gracefully.

7. 🔒 **Upgraded Security Access Gate**  
   Integrated a flawless SHA-256 encrypted password gate directly into the main boot sequence. Utilizes pwinput to mask keystrokes visually and locks the system down entirely after 3 failed attempts before the GUI or Brain are allowed to load.
